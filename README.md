# ai-pingpong

3D 탁구 게임에서 두 AI가 **실제 강화학습(Q-러닝)** 으로 탁구를 배웁니다.
`ai-pingpong-rl.html`을 브라우저로 열면 바로 실행됩니다(Three.js를 CDN에서 불러오므로 인터넷 연결 필요).

## 학습이 되는지 확인하는 방법

학습된 AI와 **학습 안 된 AI(빈 Q-테이블)** 를 직접 붙여서 비교합니다. 두 AI는 물리, 규칙, 코드가 모두 같고 **Q-테이블 내용만** 다릅니다.
학습이 안 되고 있다면 승률은 50% 근처에 머물고, 학습이 되면 50%보다 위로 올라갑니다.

| 방법 | 어디서 | 무엇을 보나 |
|---|---|---|
| 📈 학습 곡선 | 화면 오른쪽 **학습 검증** 패널 | 체크포인트마다 학습 AI 복사본(학습 정지, ε=0)이 미학습 AI와 100점을 겨룹니다. 그 승률을 학습량에 따라 그린 곡선입니다 |
| ⚔️ 학습 AI vs 미학습 AI | 패널 상단 모드 버튼 | 🔵 블루는 지금까지 학습한 AI, 🔴 레드는 미학습 AI로 실제 경기를 보여 줍니다. 미학습 AI의 라켓은 공과 상관없이 좌우로 헤맵니다 |
| 🔬 지금 검증 | 패널 버튼 | 학습 AI vs 미학습 AI 200점과 **대조군**(미학습 vs 미학습 ≈ 50%)을 함께 보여 주고, z-점수로 우연인지 판정합니다 |
| `node verify-learning.js` | 터미널 (Node.js) | 같은 코드를 브라우저 없이 실행해 학습 곡선과 최종 판정을 출력합니다(학습 확인 시 종료 코드 0) |

빠르게 확인하는 순서: **⚡ 빠른 학습 +500판** → 곡선이 50%에서 95% 이상으로 오르는지 확인 → **⚔️ 학습 AI vs 미학습 AI** 모드에서 **시작**.

## 강화학습 구조

표 형식 **Q-러닝(TD(0))** 입니다. 행동 결과로 받은 보상만 보고 배우며, 정답 행동은 알려 주지 않습니다.

```
Q(s,a) ← Q(s,a) + α · [ r + γ · max_a' Q(s',a') − Q(s,a) ]      (종료 상태면 γ항 없음)
α = 0.15,  γ = 0.95(이동) / 0.90(샷)
ε-greedy 탐험: ε 1.0(완전 무작위) → 포인트마다 ×0.995 → 하한 0.05
```

- **에피소드**는 한 포인트(서브부터 득점까지)입니다.
- **셀프플레이**: 블루와 레드가 Q-테이블 하나를 공유해서 경험이 두 배로 쌓입니다. 모든 좌표를 자기 기준(내 오른쪽 = +)으로 바꾸기 때문에, 양쪽에서 같은 상황은 같은 상태가 됩니다.

AI가 학습으로 결정하는 것은 두 가지입니다.

| | ① 이동 (좌우 위치 선정) | ② 샷 (타구 선택) |
|---|---|---|
| 언제 | 3 물리 스텝마다 | 공에 라켓이 닿는 순간 |
| 상태 | 공이 올 때: **예상 도착 오차**(지금 속도로 오면 라켓 기준 좌우 어디로 오나) × 도착까지 남은 시간 × 내 라켓 속도 = 220가지<br>공이 갈 때: 내 위치 × 내 속도 × 공 위치 = 70가지 | 타점 높이 × 공 좌우 × 상대 라켓 좌우 × 위협도(강타/빠른 공) = 54가지 |
| 행동 | 좌우 목표 속도 5가지(◀◀ ◀ ■ ▶ ▶▶). 관성이 있어서 미리 출발하고 제때 멈춰야 합니다 | 라켓 면 6종(블록·펀치·드라이브·스매시·중간·루프) × 좌우 조준 5단계 = 30가지 |
| 보상 | 공을 맞히면 **+1**, 못 받아서 실점하면 **−1**(종료) | 포인트를 따면 **+1**, 잃으면 **−1**. 마지막 샷에 주어지고, γ를 통해 앞선 샷들까지 전파됩니다 |

학습하지 않고 기본 동작으로 처리하는 부분도 있습니다.
- 서브
- 앞뒤·높이 풋워크: 공이 오면 예측 타점의 x·y 위치로 이동합니다. 좌우(z)는 학습한 행동으로만 움직입니다.
- 샷 실행: 고른 샷을 네트 위로 넘겨 코트 안에 떨어뜨리는 보정입니다(실행 오차 포함).

반응 지연은 9스텝, 강타가 올 때는 4스텝입니다. AI는 그만큼 이전 시점의 공을 보고 판단합니다.

### 이전 버전과 달라진 점

이전 버전은 라켓 이동을 물리 예측으로 완벽하게 계산했고, 업데이트도 `Q ← Q + α(r − Q)`였습니다. 다음 상태와 할인율이 없는 1단계 밴딧 방식이었습니다.
그래서 학습과 상관없이 실력이 거의 같았습니다. 측정해 보면 미학습 AI끼리도 평균 랠리가 26회였고, 3000판 학습한 AI도 미학습 AI를 상대로 승률이 55~60%에 그쳤습니다.
지금은 학습 전 AI의 리턴 성공률이 약 30%이고, 수백 판 학습하면 약 98%로 오릅니다.

## 파일 구성

- `ai-pingpong-rl.html`: 게임 전체입니다. `<script id="rl-core">`에는 물리, 규칙, Q-러닝 코어가 들어 있고 DOM이나 Three.js를 쓰지 않습니다. 그 아래 스크립트는 3D 렌더링과 UI입니다.
- `verify-learning.js`: HTML에서 `rl-core`를 그대로 꺼내 Node에서 학습과 검증을 실행합니다.
